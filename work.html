Boston TransXpress · Software development

End-to-end transportation booking and payment platform

I built a custom pre-AI-era transportation booking platform from scratch, integrating Google Maps routing, dynamic toll and time-of-day pricing, database ride persistence, and full PayPal authorization, capture, tipping, and IPN workflows.

Software development Google Maps API PayPal IPN & Auth/Capture Database architecture

Challenge

Booking private rides required accurate fare quotes factoring in distance, tolls, and time-of-day traffic, paired with a payment flow that held funds at booking and settled final charges (plus tips) only after ride completion.

Approach

I engineered a custom full-stack web application integrating the Google Maps API to calculate route distance, tolls, and time-of-day travel duration, persisting bookings in a relational database and connecting PayPal APIs for authorization, capture, tipping, and automated IPN status reconciliation.

Result

A self-contained booking and dispatch system that automated quoting, database record-keeping, and two-step payment settlement without manual intervention.
